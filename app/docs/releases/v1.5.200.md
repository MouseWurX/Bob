# Bob 1.5.200

Brain Engine moves onto a newer llama.cpp, and a weekly check says when the next one is ready.

## Changed

- **Brain Engine and the built-in llama.cpp are on llama.cpp b12282** (from b12032, 250 builds newer). Everything llama.cpp added in that time comes along: faster brain sharing between Bobs, support for newer brains, and many fixes. Brain Engine's own changes (the expert switch, Peek inside's trace, FNRI's dials and quicker card sharing over Wi-Fi) are all on it. The Windows CUDA download is now built for CUDA 13.5 (it was 13.4).
- **Bobs that share graphics cards need the same version of Bob.** This llama.cpp changes how cards talk to each other, so a Bob still on an older version can't lend his card to one on this one (or the other way). If it happens, the brain loads on its own Bob like always. Update every Bob that takes part. New line in Help: "Can my Bobs run one big brain together?".

## New

- **A weekly check for a newer llama.cpp** (for the people who build Bob, not in the app). Every Monday GitHub tries Brain Engine's changes on the newest llama.cpp and builds it. When it works, it opens one issue, "New Brain Engine ready on llama.cpp bNNNN - rebuild it?". Nothing in Bob changes until someone says yes. See `app/engine/README.md`, "Moving to a newer llama.cpp".
