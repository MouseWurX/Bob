# Voice samples that ship with Bob

Short clips of Bob's sample line in a few Kokoro voices, named `kokoro-<voice>.mp3` (or `.wav`).
Kokoro-82M is Apache-2.0, so audio made with it can be shipped. Make or refresh them on the PC with
`node installer/make-voice-samples.js` while Bob is running (`--all` for every voice).

Piper voices are not shipped here: their voice data licences vary (some are personal use only), so
Bob plays them from Piper's own sample page, and only when the button is clicked.
