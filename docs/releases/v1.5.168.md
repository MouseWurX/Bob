# Bob 1.5.168

The Lab's Challenges tab gets **Simple** and **Professional** modes.

- **Simple** is the tab as it was: tick the challenges, run them, read the score.
- **Professional** adds run settings: temperature, seed, thinking on or off, how much room (tokens) the brain gets, and up to five runs. Repeated runs show the lowest, highest and average score. A run with settings other than the scoreboard's (temperature 0, thinking off, 8,192 tokens) is a study: it gets its report and its log, and the scoreboard stays as it is.
- **The question log**: every run now keeps each question, the brain's answer and the result. In Professional, **Show the question log** under a finished run lists them (the misses first), and **Save the log** keeps it as JSONL or a spreadsheet in the Lab's results folder.
- **Your own challenges**: import a pack as JSON (paste it or pick a file), with plain checks only: letter, number, contains, exact, pattern, declines, answers. No code runs from a pack. They never go on the scoreboard. Help has the format and an example.
- **Guard rails in detail**: "didn't over-refuse" split by setting (everyday questions, stories and writing, your own things, how things work, work), how many answers came with a lecture or a pile of warnings, and how the replies sounded. In the sandbox, Save as lesson can tag a lesson's setting and how the reply sounded, and Held the line counts tagged lessons under their setting.
- The switch is a setting (`labMode`), Simple unless you change it. Changing it, importing packs and saving logs work only on the replicant matrix running the Lab.
- Help: The Lab's Challenges tab updated. Tests in `test/run-lab-test.js`.
- Phone (Bob for Android): the phone sees the mode the Lab is in; changing it stays on the replicant matrix.
